### 问题清单

#### 🔴 严重问题

**问题 1：尚未达到“所有控件均由统一控件体系提供”**

- 位置：`trojan-panel-ui/src/main.js:3`、`trojan-panel-ui/src/main.js:29` 及 39 个 Vue 文件
- 问题：ElementUI 仍被全局注册，并存在 311 处直接标签使用。虽然按钮、输入框、选择框等主要交互控件多数已替换为 Liquid 控件，表格、表单布局、弹窗、菜单、卡片、提示与部分下拉仍依赖 ElementUI，再由全局 CSS 覆盖外观。
- 风险：ElementUI 升级、DOM 结构变化或局部 scoped 样式都可能穿透覆盖层，使个别页面重新出现旧风格。
- 建议：将仍需保留的结构型 ElementUI 能力封装到统一 Liquid Adapter；如果目标是彻底移除 ElementUI，则按 Dialog/Table/Form/Menu/Message 的顺序提供对应 Liquid 模块并逐页迁移。

**问题 2：全站颜色还没有单一事实来源，无法保证完整换色**

- 位置：`trojan-panel-ui/src/styles/liquid-glass.scss:3`、`trojan-panel-ui/src/styles/prototype-runtime.scss:33`
- 问题：两份样式文件重复定义亮暗令牌，部分数值不同；组件和页面中仍约有 243 处非令牌硬编码颜色。
- 风险：替换 `--accent` 只能改变部分控件，登录页、仪表盘卡片、开关参数、导航头像、旧 TagsView、状态文字与图表仍可能保留原色，出现不属于所选色系的色块。
- 建议：合并为一个设计令牌入口，并把硬编码颜色迁移为语义令牌；禁止业务页面直接使用色值。

**问题 3：预检门禁当前失败**

- 位置：全局 Vue 源码
- 问题：`npm run lint` 报告 130 个既有错误。
- 风险：后续批量替换控件或主题令牌时无法使用全量 lint 区分新增问题与历史问题。
- 建议：先建立当前基线或分批清理，再将 lint 作为主题重构门禁。

#### 🟡 建议修改

**问题 4：面板与悬浮层视觉相近，但实现分散**

- 位置：`liquid-glass.scss`、`prototype-runtime.scss`、`LiquidSelect/index.vue`
- 问题：Dialog、MessageBox、Popover、Dropdown、Picker 和自定义 LiquidSelect 都已经采用玻璃背景、描边、阴影和模糊，但分别维护各自组合，半透明度、圆角与高光并非来自统一的“浮层配方”。
- 建议：定义 `--surface-panel-*`、`--surface-popover-*` 和可复用的 glass mixin/class，让一级面板、二级面板、悬浮层只选择层级，不自行拼颜色。

**问题 5：状态色、品牌色、图表色混在同一层级**

- 位置：仪表盘 PanelGroup、图表配置、各表单 switch 参数
- 问题：红/绿/蓝/紫等颜色既被用作状态，也被用作装饰或图表序列，部分直接写在模板属性和 JS 返回的 style 字符串中。
- 建议：拆分为品牌色、反馈状态色和数据可视化色三个语义组，颜色主题只替换品牌/环境色，错误、警告、成功色保持可访问性语义。

#### 🟢 可选优化

**问题 6：主题模块的 Interface 只能表达亮暗模式**

- 位置：`trojan-panel-ui/src/utils/theme.js:3`
- 建议：把主题模块加深为一个小 Interface，例如 `applyTheme({ mode, palette })`；实现内部校验主题、设置 `data-theme`/`data-palette`、同步 `color-scheme`。调用方不应直接操作 CSS 变量。

### 亮点

- 主要输入控件已有 Liquid 系列模块，样式普遍使用语义令牌。
- Dialog、Message、Notification、Popover、Picker 和下拉层已具备统一玻璃化覆盖，核心页面视觉一致性明显高于旧版。
- 当前 `data-theme` + CSS Custom Properties 已经是颜色主题系统的可用基础。
- 主题状态按运行周期保存、不写本地存储，符合既定约束。

### 颜色主题可行方案

可以实现，并且无需重写页面。建议把“主题”拆成两个正交维度：

- `data-theme="light|dark"`：只控制明暗、文字、表面、阴影和原生 `color-scheme`。
- `data-palette="blue|violet|emerald|amber|custom"`：控制强调色、环境光斑、选中态和图表色系。

主题 Module 对外只暴露 `applyTheme({ mode, palette })` 与读取当前运行时状态的 Interface；CSS 内部使用语义令牌：

- 表面：`--surface-page`、`--surface-panel`、`--surface-popover`、`--surface-control`
- 文字：`--text-primary`、`--text-secondary`、`--text-muted`
- 品牌：`--accent`、`--accent-strong`、`--on-accent`
- 状态：`--status-success-*`、`--status-warning-*`、`--status-danger-*`
- 图表：`--chart-1` 至 `--chart-8`
- 环境：`--ambient-1` 至 `--ambient-5`

这样更换色系只修改 `data-palette`，亮暗模式仍独立工作，且仍可遵循“仅在当前运行周期记住，不持久化”的要求。
